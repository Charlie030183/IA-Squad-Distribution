Ayla

Ayla é a porta operacional da IA-Squad. Ela cria um ambiente colaborativo entre IAs e ferramentas diversas, usando os repositórios do GitHub como ponto comum de trabalho.

O objetivo é simples: desenvolver com menos ruído. Em vez de cada agente ou ferramenta seguir um caminho isolado, Ayla organiza o contexto no GitHub para reduzir:

  • trabalho duplicado
  • erros de versão e de contexto
  • falhas de comunicação entre IAs e ferramentas
  • outros desvios comuns durante o desenvolvimento

Como ela conversa com as ferramentas

Ayla não trabalha sozinha. Ela articula IAs e o ambiente local do desenvolvedor.

  • VS Code + Cline — para edição assistida no projeto. Parte dessa ponte ainda usa um handoff simples (copiar e colar o pedido estruturado).
  • Terminal local — tarefas no computador podem ser disparadas automaticamente via ChatGPT, sem o desenvolvedor ter de repetir o comando à mão.
  • GitHub — é o lugar onde o trabalho fica registrado, para todas as IAs verem o mesmo estado.
