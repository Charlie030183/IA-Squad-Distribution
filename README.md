# IA Squad Distribution

Repositório público oficial para **distribuição de artefatos estáveis e explicitamente aprovados** dos projetos privados da IA Squad.

Este repositório **não é um repositório de desenvolvimento**.

## Regra de publicação

Conteúdo só pode chegar aqui após:

1. desenvolvimento no repositório privado do projeto;
2. testes e validação;
3. criação de candidato de release;
4. allowlist e verificação de integridade;
5. aprovação explícita de Charlie_030183 para o candidato exato;
6. publicação pelo Ayla Release Gateway.

Push, merge, tag ou build em um projeto privado **não autorizam publicação automática**.

Código interno, documentação privada, Knowledge, Black Box, estados de IA, testes internos, credenciais e outros materiais não aprovados não pertencem a este repositório.
