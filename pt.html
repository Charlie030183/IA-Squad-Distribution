Ayla

IA-Squad

Funciona com GitHub

Autonomous Yielding Learning Assistant

Ayla é a assistente operacional para suas IAs, ela cria um ambiente colaborativo entre elas e ferramentas diversas, incluindo Grok e ChatGPT, usando a API e os repositórios do GitHub como ponto comum de trabalho.

O objetivo é simples: desenvolver com menos ruído. Em vez de cada agente ou ferramenta seguir um caminho isolado, Ayla organiza o contexto no GitHub colaborando para:

  • Reduzir trabalho duplicado.
  • Evitar erros de versão e de contexto.
  • Minimizar falhas de comunicação entre IAs e ferramentas.
  • Inibir outros desvios comuns durante o desenvolvimento das aplicações.

Isso também ajuda em projetos pequenos, como criação de jogos e aplicativos multiplataforma.

Como ela conversa com as ferramentas

Ayla não trabalha sozinha. Ela articula IAs e o ambiente local do desenvolvedor.

  • VS Code + Cline — para edição assistida no projeto. Parte dessa ponte ainda usa um handoff simples (copiar e colar o pedido estruturado).
  • Terminal local — tarefas no computador podem ser disparadas automaticamente via ChatGPT, sem o desenvolvedor ter de repetir o comando à mão.
  • GitHub — é o lugar onde o trabalho fica registrado, para todas as IAs verem o mesmo estado.

Backup e restauração

Antes de apagar um repositório ou material autorizado para exclusão, Ayla cria um backup verificado no GitHub. Esse backup fica em quarentena por 7 dias. Se for pedido, ela é capaz de restaurar o que foi preservado. Se o backup falhar, a exclusão não segue.
